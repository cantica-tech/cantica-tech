# `backlog` — entity definition (v1)

| Field | Value |
|---|---|
| **Entity type** | `backlog` |
| **Version** | 1 |

## Description

`development/BACKLOG.md` is a generated summary of open work and blockers —
open bugs by severity, in-progress requirements, unlinked work items, rules
with no open work, feature ideas with no requirement yet, and every active
roadmap's rows. Unlike every other deployed artifact, it's fully regenerated in
place by `/show-backlog` each time — hand-editing it is pointless, since the
next run overwrites it in full.

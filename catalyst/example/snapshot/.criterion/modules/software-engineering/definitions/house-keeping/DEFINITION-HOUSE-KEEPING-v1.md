# `house-keeping` — entity definition (v1)

| Field | Value |
|---|---|
| **Entity type** | `house-keeping` |
| **Version** | 1 |

## Description

An `HK-NNNNNN` document tracks development of tools, scripts, or process that
support the development effort itself rather than product behavior — CI, test
harnesses, release tooling. It still requires a rule target, since house-
keeping work exists to keep some rule enforceable, verifiable, or documented,
even indirectly. Lives under `development/house-keeping/`, registered in
`house-keeping.md`.
